# Keyboard Shortcuts

Only active on the labeling page (`/label/:pageId`). Ignored when INPUT, TEXTAREA, or SELECT elements have focus.

## Tool Mode

| Key | Action |
| ---- | ------ |
| `1` | Select mode |
| `2` | Draw mode |
| `3` | Pan mode |

## Display

| Key | Action |
| ---- | ------ |
| `R` | Toggle reading order overlay |

## Editing

| Key | Action |
| ---- | ------ |
| `X` | Delete selected element(s) (including multi-selection) |
| `Escape` | Deselect |

## Page Navigation

| Key | Action |
| ---- | ------ |
| `Q` | Previous page |
| `E` | Next page |

## Save

| Key | Action |
| ---- | ------ |
| `Ctrl+S` / `Cmd+S` | Save (prevents browser default action) |

## Help

| Key | Action |
| ---- | ------ |
| `` ` `` | Toggle keyboard shortcut help popover |

You can view the full shortcut list by clicking the keyboard icon on the right side of the header or pressing the `` ` `` key.

## Mouse

| Action | Result |
| ------ | ------ |
| Mouse wheel | Zoom in/out centered on pointer position |
| Middle button drag | Pan - in any mode |
| Select mode click | Single element selection |
| `Ctrl/Cmd` + click | Toggle element select/deselect (multi-selection) |
| `Shift` + click | Range selection from anchor |
| Element list top `↑` / `↓` | Move selected elements up/down at once |
| Select mode drag | Move selected element |
| Draw mode drag | Create new bbox (default: text_block) |
| Pan mode drag | Pan |

## Unsaved Changes Warning

When attempting to leave the page with unsaved changes, a `beforeunload` warning is displayed.
